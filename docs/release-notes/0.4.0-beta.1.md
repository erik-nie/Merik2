# Merik 0.4.0 Beta 1

The first beta of **Merik**, a live MIDI player built for the stage. Big step since the alpha: Merik can now play **recorded audio stems** next to MIDI, and has a **click track** you can send to its own output.

## What's new

- **Audio stems (`.merik` files).** A `.merik` is a zip with audio stems per family (`1-drums.flac`, `7-void.mp3`, ...), optional `song.mid`, `click.wav`, `chords.json` and `lyrics.json`. No manifest to write: Merik recognises the files by name. Per family **audio wins over MIDI**, and anything missing falls back to the MIDI file. Mix MIDI and audio freely, for example MIDI plus a live vocal stem. Stems keep their name on the family button. See the README and `docs/merik-format.md`; a test song is in `docs/demo`, and `scripts/make-merik.py` makes your own.
- **Click track on family 8.** Generated from the tempo and time signature of the song and sample-accurate with the music. Fader = volume, switch = on/off. Own click audio (`click.wav`) is supported too.
- **Separate outputs.** Settings → Audio: choose a main output (stereo pair or one channel), the click output (any other channel or pair, or a split of click left / music right), and an output per audio-stem family. Handy with a multichannel interface or a mixer, for example the click to the drummer only.
- **Family labels and meters.** Each family shows **AUDIO**, **MIDI** or **CLICK** and a level meter, in the app and in the browser mixer. The song list tags files that contain **MIDI** and/or **AUDIO**.
- **Settings:** a separate **Soundfont** tab, new tab design, and an audio device panel with all outputs of your interface.
- **Spacebar** is play/pause. **Command-click** (macOS) or **Ctrl/Alt-click** (Windows) on **Lyrics** opens the web page with your control key. `.mid`, `.kar` and `.merik` files can be opened from the Finder or Explorer ("Open with").
- **Families:** 7 is now **Others** (FX and other), 8 is **Click**.
- **Faster:** selecting a setlist is snappy again. Setlists are stored in a compact form, so saving takes about 12 ms instead of 380 ms. Your existing setlists are converted automatically on first start.
- **Update notification** (from the previous alpha): Merik tells you at startup when a newer version is available. Turn it off or check by hand under **Settings → General**.

## Install

**macOS (Apple silicon)**

1. Download `Merik-0.4.0-beta.1-arm64.dmg`, open it and drag **Merik** onto **Applications**.
2. The app is **not notarized**, so macOS blocks the first start. Right-click **Merik.app**, choose **Open** and confirm. If it is still blocked, run this in Terminal:
   ```sh
   xattr -dr com.apple.quarantine /Applications/Merik.app
   ```

**Windows (64-bit)**

1. Download `Merik-0.4.0-beta.1-windows-x64.zip` and extract it to a folder.
2. Run `Merik.exe`. If SmartScreen warns about an unknown app (the build is not code-signed), click **More info**, then **Run anyway**.
3. Allow Merik on private networks when Windows asks, to use the lyrics and remote control web page.

On both systems, choose a General MIDI SoundFont (`.sf2`) under **Settings → Soundfont**. Merik does not include one. `MatrixSF_v2.1.5.sf2` is a great free option, but many others exist.

## Known limits

- Audio stems and the separate outputs are new and have mostly been tested on macOS. Please report problems on Windows.
- Transpose is not available for songs with stems.
- Stems are loaded into memory when a song loads (about 11 MB per minute per stereo stem).
- MIDI out uses a portable output on Windows, so timing is less tight than on macOS.
- Intel Macs and Linux are not supported yet.
- After the first start, setlists are stored in a new format; an older Merik version no longer reads them from the same settings file.
