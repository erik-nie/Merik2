# Merik Studio 1.0.0

**Merik is now called Merik Studio.**

The desktop app for macOS and Windows has a new name: **Merik Studio**. The name **Merik** now belongs to the iPad app, which plays the `.merik` files you make here. Merik Studio stays free and is still where you render MIDI to audio and create `.merik` files.

## What's new

- **New name.** The app, the window, the installer and the lyrics and remote control web page now say Merik Studio. The web page is still at `http://merik.local`, so tablets find it as before.
- **Your settings and setlists are kept.** Merik Studio reads them from the same place as Merik 0.7.
- Same features as Merik 0.7.3.

## Install

**macOS**

1. Download the file for your Mac: `Merik-Studio-1.0.0-arm64.dmg` (Apple silicon, macOS 15 or later) or `Merik-Studio-1.0.0-intel.dmg` (Intel, macOS 15 or later). Open it and drag **Merik Studio** onto **Applications**, then start it.
2. Coming from Merik 0.7 or older? The old **Merik** app stays in Applications next to Merik Studio. You can move it to the Trash; your settings and setlists are not inside it.

**Windows (64-bit)**

1. Download and run `Merik-Studio-1.0.0-windows-x64-setup.exe` and follow the installer. It installs for your own account and needs no administrator rights. An existing Merik installation is updated in place: the old program and its shortcuts are replaced by Merik Studio.
2. The installer is **not code-signed**, so Windows SmartScreen may say "Windows protected your PC". Click **More info**, then **Run anyway**.
3. If there is no "Run anyway" button, SmartScreen is set to block: open **Windows Security, App & browser control, Reputation-based protection settings** and set **Check apps and files** to **Warn** (or **Off**).
4. If Windows 11 blocks it with **Smart App Control** (no "Run anyway" either), open **Windows Security, App & browser control, Smart App Control settings** and choose **Off**. On some Windows 11 versions Smart App Control cannot be turned on again afterwards.
5. Allow Merik Studio on private networks when Windows asks, to use the lyrics and remote control web page.

On all systems, choose a General MIDI SoundFont (`.sf2`) under **Settings → Soundfont** if you have not done so before. Merik Studio does not include one.

## Known limits

- `merik.local`, port 80 and rendering with the internal SoundFont have been tested on macOS only. Some Android devices cannot resolve `.local` names; use the IP address there.
- A `.merik` of 4 GB or more cannot be made. Transpose is not available for songs with stems. Linux is not supported.
