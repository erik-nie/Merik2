# Merik 0.2.0-alpha.2

The second alpha of **Merik**, a live MIDI player built for the stage. This release adds a **Windows version** and a beat indicator.

## What's new

- **Windows (alpha):** Merik now runs on Windows 10 and 11 (64-bit). Download the zip, extract it and run `Merik.exe`.
- **Beat indicator:** the time signature (for example 4/4) is shown top right, with LEDs that follow the beat. The first beat has its own colour. It is in the app and on the web page, where it slides under the countdown when that is shown.
- **Next song is queued:** when a song in a setlist ends and *Auto play next song* is off, the next song is loaded and ready, but not started.
- **macOS:** the download now runs on **macOS 14 or later** (alpha 1 needed macOS 27). The disk image has a window with an arrow from Merik to the Applications folder.
- Built and packaged automatically on GitHub.

## Install

**macOS (Apple silicon)**

1. Download `Merik-0.2.0-alpha.2-arm64.dmg`, open it and drag **Merik** onto **Applications**.
2. The app is **not notarized**, so macOS blocks the first start. Right-click **Merik.app**, choose **Open** and confirm. If it is still blocked, run this in Terminal:
   ```sh
   xattr -dr com.apple.quarantine /Applications/Merik.app
   ```

**Windows (64-bit)**

1. Download `Merik-0.2.0-alpha.2-windows-x64.zip` and extract it to a folder.
2. Run `Merik.exe`. If SmartScreen warns about an unknown app (the build is not code-signed), click **More info**, then **Run anyway**.
3. Allow Merik on private networks when Windows asks, to use the lyrics and remote control web page.

On both systems, choose a General MIDI SoundFont (`.sf2`) under **Settings → Audio**. Merik does not include one. `MatrixSF_v2.1.5.sf2` is a great free option, but many others exist.

## Known limits of the Windows alpha

- It has had little testing, so expect rough edges.
- MIDI out uses a portable output on Windows, so timing is less tight than on macOS.
- Intel Macs and Linux are not supported yet.
