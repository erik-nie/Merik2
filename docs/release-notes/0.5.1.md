# Merik 0.5.1

A small update to **Merik 0.5.0** with two big conveniences: Merik now runs on **Intel Macs**, and it can **make a `.merik` file for you**.

## What's new

- **Intel Macs.** There is now a separate download for Intel Macs, `Merik-0.5.1-intel.dmg` (macOS 15 or later). Apple silicon keeps `Merik-0.5.1-arm64.dmg` (macOS 14 or later).
- **Create a .merik file from inside Merik.** Settings → General → *Create a .merik file from a folder...*. Choose the folder with your stems and Merik:
  - shows what it recognised and what it ignored (by file name: `1-drums.wav`, `7-void.mp3`, `song.mid`, `click.wav`, `chords.json`, `lyrics.json`, ...),
  - warns about stems of different lengths or sample rates, more than one MIDI file, or a missing MIDI file or tempo,
  - converts WAV to FLAC if you want (lossless: 16- and 24-bit come back bit for bit identical; 32-bit float becomes 24-bit),
  - saves the `.merik` **without compression**, so it can be streamed and loads instantly,
  - and can add the new file straight to the current setlist.

  This is much more stable than zipping by hand. The manual way is still described in the README and in `docs/merik-format.md`, at the bottom, for the command line and scripts.

## Install

**macOS**

1. Download the file for your Mac: `Merik-0.5.1-arm64.dmg` (Apple silicon) or `Merik-0.5.1-intel.dmg` (Intel). Open it and drag **Merik** onto **Applications**.
2. The app is **not notarized**, so macOS blocks the first start. Right-click **Merik.app**, choose **Open** and confirm. If it is still blocked, run this in Terminal:
   ```sh
   xattr -dr com.apple.quarantine /Applications/Merik.app
   ```

**Windows (64-bit)**

1. Download `Merik-0.5.1-windows-x64.zip` and extract it to a folder.
2. Run `Merik.exe`. If SmartScreen warns about an unknown app (the build is not code-signed), click **More info**, then **Run anyway**.
3. Allow Merik on private networks when Windows asks, to use the lyrics and remote control web page.

On all systems, choose a General MIDI SoundFont (`.sf2`) under **Settings → Soundfont**. Merik does not include one. `MatrixSF_v2.1.5.sf2` is a great free option, but many others exist.

## Known limits

- The Intel build has had little testing. Please report problems on Intel Macs and on Windows.
- A `.merik` of 4 GB or more cannot be made (the zip format used here has no support for it).
- Streaming works for stems stored without compression. A slow or network drive can cause stutter: copy the file to a local drive.
- Transpose is not available for songs with stems.
- MIDI out uses a portable output on Windows, so timing is less tight than on macOS.
- Linux is not supported yet.
