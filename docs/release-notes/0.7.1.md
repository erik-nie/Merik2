# Merik 0.7.1

A small release: **Merik for Windows now comes as an installer** instead of a zip. The program itself is the same as 0.7.0.

## What's new

- **Windows installer.** `Merik-0.7.1-windows-x64-setup.exe` installs Merik for your own account (no administrator rights needed), adds a Start menu entry and an optional desktop shortcut, and can be removed under *Apps*. Windows may still warn about an unknown app, because the installer is not code-signed yet. A **code-signed release is on the way**.
- Documentation and website: clearer steps for the Windows warnings (SmartScreen, Reputation-based protection and Smart App Control), SoundFont advice, and new download buttons.

## Install

**macOS**

1. Download the file for your Mac: `Merik-0.7.1-arm64.dmg` (Apple silicon, macOS 14 or later) or `Merik-0.7.1-intel.dmg` (Intel, macOS 15 or later). Open it and drag **Merik** onto **Applications**.
2. The app is **not notarized**, so macOS blocks the first start. Right-click **Merik.app**, choose **Open** and confirm. If it is still blocked, run this in Terminal:
   ```sh
   xattr -dr com.apple.quarantine /Applications/Merik.app
   ```

**Windows (64-bit)**

1. Download and run `Merik-0.7.1-windows-x64-setup.exe` and follow the installer. It installs for your own account and needs no administrator rights.
2. The installer is **not code-signed** yet, so Windows SmartScreen may say "Windows protected your PC". Click **More info**, then **Run anyway**.
3. If there is no "Run anyway" button, SmartScreen is set to block: open **Windows Security, App & browser control, Reputation-based protection settings** and set **Check apps and files** to **Warn** (or **Off**).
4. If Windows 11 blocks it with **Smart App Control** (no "Run anyway" either), open **Windows Security, App & browser control, Smart App Control settings** and choose **Off**. On some Windows 11 versions Smart App Control cannot be turned on again afterwards.
5. Allow Merik on private networks when Windows asks, to use the lyrics and remote control web page.

A **code-signed release is on the way** (free code signing for open-source projects). It should remove these warnings.

On all systems, choose a General MIDI SoundFont (`.sf2`) under **Settings → Soundfont**. Merik does not include one. `MatrixSF_v2.1.5.sf2` and `MS_Basic.sf2` are good free options, but any General MIDI SoundFont works.

## Known limits

- `merik.local`, port 80 and rendering with the internal SoundFont have been tested on macOS only. Some Android devices cannot resolve `.local` names; use the IP address there.
- A `.merik` of 4 GB or more cannot be made. Transpose is not available for songs with stems. Linux is not supported yet.
