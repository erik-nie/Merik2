# Merik 0.7.2

**Merik for macOS is now signed and notarized by Apple**, so it opens without the right-click and Terminal steps. The program itself is the same as in 0.7.1.

## What's new

- **macOS: signed and notarized.** Open the DMG, drag **Merik** onto **Applications** and start it. macOS may ask once to confirm that the app was downloaded from the internet. The `xattr` command is no longer needed.
- **Windows installer** (from 0.7.1): `Merik-0.7.2-windows-x64-setup.exe`. It is **not code-signed yet**, so Windows may warn; a **code-signed Windows release is on the way**.

## Install

**macOS**

1. Download the file for your Mac: `Merik-0.7.2-arm64.dmg` (Apple silicon, macOS 14 or later) or `Merik-0.7.2-intel.dmg` (Intel, macOS 15 or later). Open it and drag **Merik** onto **Applications**, then start it.

**Windows (64-bit)**

1. Download and run `Merik-0.7.2-windows-x64-setup.exe` and follow the installer. It installs for your own account and needs no administrator rights.
2. The installer is **not code-signed** yet, so Windows SmartScreen may say "Windows protected your PC". Click **More info**, then **Run anyway**.
3. If there is no "Run anyway" button, SmartScreen is set to block: open **Windows Security, App & browser control, Reputation-based protection settings** and set **Check apps and files** to **Warn** (or **Off**).
4. If Windows 11 blocks it with **Smart App Control** (no "Run anyway" either), open **Windows Security, App & browser control, Smart App Control settings** and choose **Off**. On some Windows 11 versions Smart App Control cannot be turned on again afterwards.
5. Allow Merik on private networks when Windows asks, to use the lyrics and remote control web page.

A **code-signed Windows release is on the way** (free code signing for open-source projects). It should remove these warnings.

On all systems, choose a General MIDI SoundFont (`.sf2`) under **Settings → Soundfont**. Merik does not include one. `MatrixSF_v2.1.5.sf2` and `MS_Basic.sf2` are good free options, but any General MIDI SoundFont works.

## Known limits

- `merik.local`, port 80 and rendering with the internal SoundFont have been tested on macOS only. Some Android devices cannot resolve `.local` names; use the IP address there.
- A `.merik` of 4 GB or more cannot be made. Transpose is not available for songs with stems. Linux is not supported yet.
