# Merik 0.6.0

A big update for **Merik**, the live MIDI player for the stage: you can now **render MIDI files to audio** through a hardware sound module or a software synth, **search your setlists** (also from the browser), **insert a song** without losing your place, and set a **volume per song**.

## What's new

- **Render MIDI files to audio stems.** Settings → Tools → **Render MIDI files...** plays each MIDI file through a MIDI output (a hardware module such as a Boss DS-330, or a software synth in a host like MainStage, Logic or Bidule via IAC and a virtual audio device such as BlackHole) and records every family as its own stem (up to 7 passes), then saves a **.merik** per song.
  - An interactive **level test** (piano and drums at full velocity, target about -6 dB) and a **delay measurement**. The delay is stored in the file (`delay.json`), so MIDI and audio play together.
  - Choose any audio input device and channels (mono or stereo), a progress window with the song, the pass and the time left, and a **Stop** button.
  - Options: keep the WAV files, FLAC in the `.merik`, a General MIDI reset (off by default), and a **demo render** (the first 30 seconds of every track). Merik asks before it overwrites an existing result.
  - See `docs/render-external-module.md`. On macOS, the first time you are asked to allow Merik to use the microphone (that is how macOS names an audio input).
- **Search** the setlists: a magnifier next to the song list (or Ctrl/Cmd+F) and, with the control key, in the web page (with your tablet's keyboard). From 3 letters you get a list of candidates, in the current or in all setlists.
  - **Play now** or **Play next**: a "next" song waits until the current one ends and shows in the *Next:* field. Afterwards the setlist goes on where it was; the **Continue** button takes you back to that setlist and position.
- **Volume per song** (a difference in dB): a control next to the transpose control and a right-click submenu. Audio stems and the built-in SoundFont can go louder or softer; an external MIDI device gets scaled channel volumes. **Transpose** is now remembered per song as well.
- **Click track on at startup** is a setting (Settings → General), on by default.
- **Web page:** a neat "Merik is not running" message that reconnects by itself, and the title of a `.merik` is shown correctly.
- **Setlists:** right-click on the empty space below the setlists for **New setlist**. The Load button is gone; a folder icon next to "+" opens a MIDI file once. Compact transpose and volume controls and list tags, and `.DS_Store` files are ignored.

## Install

**macOS**

1. Download the file for your Mac: `Merik-0.6.0-arm64.dmg` (Apple silicon, macOS 14 or later) or `Merik-0.6.0-intel.dmg` (Intel, macOS 15 or later). Open it and drag **Merik** onto **Applications**.
2. The app is **not notarized**, so macOS blocks the first start. Right-click **Merik.app**, choose **Open** and confirm. If it is still blocked, run this in Terminal:
   ```sh
   xattr -dr com.apple.quarantine /Applications/Merik.app
   ```

**Windows (64-bit)**

1. Download `Merik-0.6.0-windows-x64.zip` and extract it to a folder.
2. Run `Merik.exe`. If SmartScreen warns about an unknown app (the build is not code-signed), click **More info**, then **Run anyway**.
3. Allow Merik on private networks when Windows asks, to use the lyrics and remote control web page.

On all systems, choose a General MIDI SoundFont (`.sf2`) under **Settings → Soundfont**. Merik does not include one. `MatrixSF_v2.1.5.sf2` is a great free option, but many others exist.

## Known limits

- Rendering through an external module has been tested on macOS only. Please report problems on Windows.
- With some software synths the drums stay silent after a General MIDI reset: leave that option off (the default).
- A `.merik` of 4 GB or more cannot be made.
- Streaming works for stems stored without compression. A slow or network drive can cause stutter: copy the file to a local drive.
- For an external MIDI device, a song volume above the maximum is not possible (only where the file's own volume is below the maximum).
- Transpose is not available for songs with stems. Linux is not supported yet.
