# Merik Studio 1.0.1

**The update check now uses the website.**

## What's new

- **Update check via merik.app.** Merik Studio asks `merik.app/studio/latest.json` whether a newer version exists, instead of GitHub. Nothing else changes in how it works: a pill appears next to the song counter, and you can skip a version.
- **Links.** The Windows installer, the README and the licence notice point to the website. Source code (GNU AGPL v3) is available at `merik.app/studio/source/`.

## Install

Download Merik Studio 1.0.1 from the website, or let the update pill take you there.

**macOS:** open the DMG and drag **Merik Studio** onto **Applications**.
**Windows:** run `Merik-Studio-1.0.1-windows-x64-setup.exe`. An existing installation is updated in place. The installer is not code-signed, so Windows may warn: click **More info**, then **Run anyway**.

On all systems, choose a General MIDI SoundFont (`.sf2`) under **Settings → Soundfont** if you have not done so before.

Merik Studio is free software under the GNU AGPL v3. Third-party licences are in the app download and on the website.
