# The .merik format (audio stems)

A `.merik` file is a normal **zip file** with a different extension. Merik plays the audio stems in sync with the click, lyrics, chords and (optional) MIDI.

```
My Song.merik
├── manifest.json      required
├── song.mid           optional: tempo, time signature, lyrics, chords, MIDI parts
└── stems/
    ├── 1-drums.flac   wav, flac or mp3
    ├── 2-bass.flac
    └── ...
```

## manifest.json

```json
{
  "format": 1,
  "title": "My Song",
  "bpm": 100,
  "timeSignature": [4, 4],
  "durationSeconds": 215.0,
  "timing": { "midi": "song.mid", "audioOffsetSeconds": 0.0 },
  "stems": [
    { "family": 1, "file": "stems/1-drums.flac", "gainDb": 0 },
    { "family": 2, "file": "stems/2-bass.flac",  "gainDb": -1.5 }
  ]
}
```

| Field | Meaning |
|---|---|
| `stems[].family` | 1 Drums, 2 Bass, 3 Guitars, 4 Keys, 5 Strings, 6 Winds, 7 Others. (8 is the click, generated by Merik.) |
| `stems[].gainDb` | Optional level correction for this stem. |
| `timing.midi` | MIDI file inside the zip (default `song.mid`). |
| `bpm`, `timeSignature` | Only used when there is **no** MIDI file: Merik makes a tempo map for the click and beat LEDs. |
| `durationSeconds` | Only used without MIDI; default is the length of the longest stem. |
| `timing.audioOffsetSeconds` | Positive: the audio starts later than the MIDI. |

## How it plays

- Each family with a stem plays from audio; the **family faders and R buttons** (app, web, controller) control the stems. Families **without** a stem still play from the MIDI file (a hybrid song is fine). If a family has a stem, its MIDI notes are not played.
- The click (family 8) follows the tempo and time signature of the MIDI file (or `bpm`/`timeSignature`), so it stays in sync with the stems **if the stems start exactly at the start of the MIDI/tempo grid** (bar 1 at time 0).
- **Transpose** is not available for songs with stems.
- Stems are decoded to memory when the song is loaded (about 11 MB per minute per stereo stem at 48 kHz).

## Stem requirements

- All stems the same length and starting at time 0 (export from the DAW with the same start point). Mono or stereo; Merik converts to the sample rate of the audio device.
- Prefer FLAC (lossless). MP3 works but has a start delay that can shift timing.

## Making a .merik

Use [scripts/make-merik.py](../scripts/make-merik.py) (needs only Python 3):

```bash
# stems named 1-drums.flac, 2-bass.flac, ... in a folder, plus a MIDI file
python3 scripts/make-merik.py pack "My Song.merik" --folder stems/ --midi song.mid

# without MIDI: give the tempo (used for the click)
python3 scripts/make-merik.py pack "My Song.merik" --folder stems/ --bpm 96 --sig 4/4

# or pick the files yourself
python3 scripts/make-merik.py pack "My Song.merik" --stem 1=drums.wav --stem 2=bass.wav

# a synthetic test song
python3 scripts/make-merik.py demo "Stems Demo.merik"
```

You can also build the zip by hand with any zip tool. Tip: store the audio files without compression.

A test song is included: [docs/demo/Stems Demo.merik](demo/Stems%20Demo.merik) (drums, bass, keys, strings, others as audio; the guitar part plays from the MIDI file through the SoundFont, the MIDI bass part is replaced by the bass stem).
